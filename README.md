# Spotify Music Player

A Spotify-inspired music player interface developed using HTML, CSS, and JavaScript. The project implements a responsive playlist layout with interactive playback controls, song navigation, progress tracking, and album artwork.

## Features

- Play and pause functionality
- Next and previous track navigation
- Interactive progress bar
- Dynamic song information
- Album artwork integration
- Spotify-inspired user interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
